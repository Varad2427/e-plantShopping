# Paradise Nursery — Plant Shopping Application

## Project Name
**Paradise Nursery Shopping Application**

## Project Description
Paradise Nursery is a React-based plant shopping application that allows users to browse houseplants, explore plant categories, and add plants to a shopping cart. Users can manage quantities, remove plants, and view subtotals and the total cart amount.

## Features
- Welcome landing page with a Get Started button
- About Us section
- Plant categories and product cards with images, descriptions, and prices
- Add-to-cart functionality
- Shopping cart quantity management
- Remove items from the cart
- Automatic subtotal and total calculations
- Checkout placeholder displaying "Coming Soon!"

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite
- npm

## Installation and Setup

1. Clone the repository:
   `git clone https://github.com/Varad2427/e-plantShopping.git`

2. Enter the project directory:
   `cd e-plantShopping`

3. Install dependencies:
   `npm install`

4. Start the development server:
   `npm run dev`
